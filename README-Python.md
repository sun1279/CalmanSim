# ColorLab · Python SDR 测量工作台

已实现 CA410 / Murideo SIX-G 串口驱动、目标计算、39 个 Pattern、单点/序列测量、实时表格与图表、色域覆盖率、色差、自动保存及取消续测。Pattern 表格包含按目标 XYZ 计算的 `target_x`、`target_y`，第一列默认宽度为 160 像素。默认模拟模式可在没有硬件时运行完整流程。

## 启动

首次使用请按下方步骤创建 `.venv` 并安装依赖，随后可双击 **`start-colorlab.cmd`**，或运行：

```powershell
cd C:\Projects\CalmanSim
.\.venv\Scripts\python.exe -m calman_py
```

在其他电脑安装：

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e ".[test]"
.\.venv\Scripts\python.exe -m calman_py
```

依赖为 NumPy、pyserial、PySide6-Essentials。运行不加载 Calman DLL、不依赖 Calman 启动或授权服务。仅分析脚本需要额外安装 `.[analysis]`。

## 无硬件体验

1. 保持“模拟设备”，选择模拟面板，点击“连接设备”。
2. 选择目标色域、参考白、Gamma、目标黑/白亮度、8/10 bit 和 Full/Limited。
3. 选择图表页签决定测量模式，再点击“测量序列”；也可以在当前模式的表格选中一个色块，点击“测量选中色块”。
4. 查看 CIE xy、灰阶亮度、GammaPoint / GammaAbsolute / 有效 Gamma、ΔE 曲线及数据表。`ΔE00 LC` 表示亮度补偿后的色差。
5. 测量结果逐点自动写入 `output/sessions/`。可以另存 JSON、导出 CSV，或断开设备后打开已有会话。

“停止”会等待当前读数返回，随后保留结果；连接相同设备/模拟面板后可继续未完成序列。改变色域、白点或码值格式开始新会话；改变 EOTF、指数、黑白亮度、参考来源或软件校正会重算已有数据，保留原始 XYZ 和实际码值。已完成会话内可重测单点，所需次数全部成功采样后替换该点。

### 计算、参考和采样设置

左侧“计算与校正”和“测量流程”可滚动查看。新会话默认手动黑白参考、GammaPoint、单次采样、无软件校正，平均/最大色差默认排除黑场。

- 黑位可选手动、实测或随 EOTF；随 EOTF 时 BT.1886 使用实测黑场，Power/sRGB 使用手动黑位。白场可选手动亮度或实测亮度。选择实测白场不会把实测白色度作为 Lab 参考白，目标色域的白点保持有效。
- 实测参考缺失或黑位不低于白场时，目标亮度、Gamma 和色差显示待测/无效。软件不会补打参考色块：例如七点色域中没有黑场，选择实测黑位时仍只测七点；六点色域面积可以独立计算。
- 每点可采样 1–100 次，设置采样间隔；先对原始 XYZ 求平均，再计算派生结果。JSON 保留全部样本、状态、探头编号、时间与 XYZ 标准差。任一样本含负 XYZ 时，不将其平均后伪装成有效色差。
- 可导入带 `name`、`matrix`（3×3）和可选 `offset`（三项）的 JSON 软件校正。计算使用 `matrix @ raw_xyz + offset`；原始 XYZ 不变，重算不会重复施加矩阵。示例见 [docs/xyz-correction.example.json](docs/xyz-correction.example.json)。这与 CA410 内部校准通道是两层设置，避免重复施加同一校正。
- 可选完成/停止后显示全场黑色；默认关闭。该辅助画面不作为测量记录、不增加点数。通信失败时先保留结果并关闭失效连接，不承诺还能成功改变画面。
- 不完整的一组重复采样保存在 JSON 的 `metadata.partial_acquisition` 中，不替换旧的完整测量点。续测会重新采集该点；完整旧点可使用单点重测。

### 按页签选择测量内容

| 当前页签 | 点击“测量序列”时发送 |
|---|---|
| CIE xy / 色域 | 白、R、G、B、C、M、Y，共 7 点，不发送黑场或 ColorChecker |
| 灰阶亮度 | 默认 17 点，可选 33、65、129 等或输入自定义点数；所有点的 R=G=B |
| Gamma 曲线 | 与“灰阶亮度”相同，共用同一组灰阶结果 |
| 色准 ΔE | Python 当前完整库，共 39 点；尚不包含 SG / Video 集合 |

灰阶点数包含黑、白端点。各点在信号码值范围内等间隔取样并舍入到整数，步长最多相差 1，绕过“信号百分比取整”。例如 8 bit Full 的 33 点从 `0, 8, 16, …, 255` 取样；Limited 则覆盖 16–235。最大点数受可用码值数限制：8 bit Full 为 256，Limited 为 220。

切换页签本身不会发送信号。色域、灰阶、色准保留各自当前结果；不同灰阶点数也分别保留结果。正在测量时切换图表不会改变已经开始的序列，下一次测量才采用新页签的模式。继续未完成序列始终使用会话中保存的码值与顺序，导入会话也会恢复模式及灰阶点数。

四个模拟面板：出厂未校准、理想参考、原生广色域未限幅、老化偏暖。模拟读数和文件均明确标记 `SIMULATED`；理想参考面板刻意输出与目标一致的结果，用于验证流程，其结果不代表真实设备精度。

命令行也可生成完整示例：

```powershell
.\.venv\Scripts\python.exe -m calman_py --simulate --output output/demo-session.json
.\.venv\Scripts\python.exe -m calman_py --simulate --profile reference --output output/reference.json
```

## 实机连接

当前没有仪器，**驱动已完成离线协议与错误处理测试，尚未完成实机连接、固件兼容性或信号输出验证**。

1. CA410 探头通过 USB 接电脑；SIX-G 的 USB 控制口接电脑、HDMI 输出接被测显示器。
2. 选择实机模式并刷新串口，分别选择两个不同的 COM 口；若系统未建立虚拟串口，先安装对应厂商驱动。
3. 设置 CA410 校准通道、同步模式和速度，然后连接。INTERNAL 可输入 0.50–240.00 Hz，MANUAL 可输入 4.0–4000.0 ms；其他模式不发送频率参数。ORG.AUTO 仅限支持的探头，设备拒绝设置时连接失败。连接后如需改变这些设置，先断开重连。
4. 将探头置于 ZERO 状态，点击零校准；完成后切回 MEASURE，再开始测量。程序不会自动执行零校准。
5. 实机驱动使用 SIX-G 的传统 **8 bit RGB** 色块命令，选择 8 bit。10 bit 保留用于理论计算及模拟，实机模式会在发送前拒绝。
6. 分辨率、刷新率、HDMI 量化范围标志在发生器端预先设置；显示器输入范围需与软件 Full/Limited 一致。软件设置 RGB / 8 bit / SDR，按所选范围发送码值；不会自动改变分辨率。SIX-G 的身份、HDMI 范围与时序尚未读回，文件明确标记为未知/面板预设，不能把码值范围当作链路范围已验证。

程序查询 CA410 身份、同步模式、通道、速度、适用的频率/曝光、零校准状态和零校准后的温差。明确未零校准时阻止测量；建议校准、温漂、低于保证量程及低电量分别提示。设备明确拒绝可选查询时记录未知；查询超时、乱码或格式错误仍终止操作。恢复测量时对照已记录的设备身份与有效设置；未获取到身份的设备无法提供完整身份校验，SIX-G 目前只能核对端口和驱动配置。

CA410 使用 38400 baud、7E2、RTS/CTS；SIX-G 使用 115200 baud、8N1。连接成功需要有效设备响应，打开串口本身不算连接成功。任何超时、校验错误或断线都会终止任务、关闭失效连接，并保留已经完成的点。重新连接后可续测；不自动重发测量或校准命令。

## 计算口径

- 色域：Rec.709/sRGB、P3-D65、DCI-P3、Rec.2020、Adobe RGB，以及已有骨架中的 NTSC 原色预设。白点可独立选择或输入 xy。
- EOTF：Power、自定义指数、分段 sRGB、BT.1886。理论目标基于实际量化码值；舍入采用中点取偶。
- Pattern：白黑、9 个信号灰、6 个 RGB/CMY、22 个 Classic 色块（18 彩色 + 4 相对白亮度灰），合计 39 个。
- XYZ 采用绝对亮度单位，目标与实测使用共同参考白计算 ΔE76、ΔE94、CIEDE2000。目标黑位的非零处理沿用 `Colorspace` 路径。零亮度目标保留归一化 Yn=1e-11 的数值下限。
- 色域覆盖率：实测六色点按 **R→Y→G→C→B→M→R** 连线形成多边形，计算它与目标色域的交集面积 / 目标面积；同时计算 xy、u′v′。目标轮廓也由当前配置的六色理论点构建。白点不参与面积，CMY 向内偏移时保留凹陷，不取凸包。面积比为完整实测多边形面积 / 目标面积，可能超过 100%；悬停“色域覆盖 xy”可查看实际面积和面积比。JSON 中记录六点轮廓、面积及 `ordered_polygon` 算法标记。六色未齐时等待，零亮度、负读数、自交或重复色点使面积无效，不回退到 RGB 三点。旧会话有完整六色读数时按新算法重算。这不是色域体积，也不以光谱轨迹作为分母。
- GammaPoint 按所选 Power、sRGB 或 BT.1886 及会话黑白参考计算；GammaAbsolute 为 `log(Y/W)/log(s)`；有效 Gamma 为 `log((Y-B)/(W-B))/log(s)`。黑白端点不产生逐点指数、不参与平均。卡片显示有效中间点的算术平均；悬停可查看其他平均值，以及保留的实测黑白归一化对数拟合。拟合是独立指标，不代替平均 Gamma。图中的目标曲线也按当前指标计算，sRGB/BT.1886 的绝对或有效 Gamma 不要求为常数。
- 黑场是否计入平均/最大色差有独立开关；该开关不改变发送序列，也不删除黑场读数。
- 负 XYZ 原样保存、标记无效，不把它裁成零参与色差统计。零亮度读数没有物理色度，不做亮度补偿。

JSON v2 包含配置、计算选项、模拟标记、时间戳、原始/校正后 XYZ、逐次采样、原始响应、实际码值、参考来源、设备状态、目标、警告、协议日志及统计。CSV 使用 UTF-8 BOM，保留原始 XYZ 列，并追加计算 XYZ、采样数、参考是否就绪、三种 Gamma 和计算口径。未就绪参考的目标与色差导出为空。两种导出均使用临时文件及原子替换；保存失败会明确报错，不宣称未成功落盘的数据已保存。

可读取旧版 v1 JSON：保留原来的手动目标、黑场参与色差统计、实测黑白有效 Gamma，标记 `legacy-v1`；再次保存升级为 v2，仍保留该标记。调整计算选项后使用新口径 `calio-sdr-v2`。旧文件的统计缓存不作为有效计算结果使用。

首版范围为 SDR 测量与验证；HDR/PQ/HLG、自动调电视、3D LUT、光谱及闪烁测量不在此版本范围内。界面的色度图不包含完整光谱轨迹。SIX-G 回复帧约定仍需用实机核对，详见分析记录。
